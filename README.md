# Reason Gallery — Save Photos with a Purpose

A clean, modern, mobile-first photo gallery web application that lets users attach specific reasons and notes to their saved photos, transforming cluttered camera rolls into intentional collections.

> **Core Philosophy:** *"Every saved photo has a reason. Every reason makes the photo easier to find and remember."*

---

## 🌟 Key Features
- **Purpose-Driven Curation:** Save photos with distinct purpose tags (*Dream / Goal*, *Inspiration*, *Buy Later*, *Remember*, *Personal*, *Other*).
- **Instant Search & Filtering:** Filter by category pills or search through titles, notes, and reasons in real time.
- **Collections View:** View your photos automatically grouped into category collections.
- **Favorites:** Star your most cherished items for quick access.
- **100% Private & Persistent:** All images and metadata remain safely stored in your browser using **IndexedDB**.
- **Backup & Restore:** Export your data as a `.json` backup file or import existing backups anytime in Settings.

---

## 🛠️ Built With
- **HTML5 & CSS3** (Custom responsive CSS with modern off-white aesthetic and mobile bottom nav)
- **Vanilla JavaScript** (ES6+)
- **IndexedDB API** (Browser database for reliable offline storage)

---

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any web browser (no build steps or server setup required).
